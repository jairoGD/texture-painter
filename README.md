# Texture Painter

Paint textures directly on 3D models in your browser. Built with [three.js](https://threejs.org/).

**[Open Texture Painter](https://jairogd.github.io/texture-painter/)**

Import a `.glb` or `.fbx` model, paint on its surface, organize layers and texture nodes, then export PNG textures. Save your work as a `.tp3d` project to continue later. Models need UV coordinates for texture painting.

Your files stay on your device. The editor runs in Chrome or Edge and uses the browser's file picker to open and save them.

## Use offline

Download the repository and double-click `index.html`. Keep the `app` folder beside it. No server or Node.js is needed to use the editor.
